# 英語のテストで単語で無双して50点とったら結構嬉しかったりする（医療英単語ドリル）

日本語を見て英語で答える、医療英単語の練習ゲームです。教科書「Word Study」の表に載っている消化器系、嚥下、聴覚の126語を収録しています。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（画面、見た目、動き） |
| `words.js` | 単語データ。単語を直すときはこのファイルだけを編集します |
| `tips.js` | 「おぼえる」モードで出す覚え方と語源 |
| `README.md` | この説明書 |

`index.html`、`words.js`、`tips.js` は必ず同じフォルダに置いてください。`tips.js` がなくてもアプリは動きますが、覚え方が出なくなります。

## 遊び方

### 手元のパソコンで試す
`index.html` をダブルクリックすると、ブラウザで開きます。インターネット接続は要りません。

### モード
- **おぼえる**：答えたあとに正解と別解が出ます。「正解にする」か「復習に回す」を自分で選びます。復習に回した語は4問あとにもう一度出て、次回からは先に出題されます。答えの下に、覚え方と語源のメモも表示します（下の「覚え方と語源について」を参照）。
- **実践テスト**：問題数（10、20、30、全部のボタンか、「自分で決める」欄に好きな数を入力）とタイマー（オフ、20秒、10秒）を選べます。答えている間は正解を見せず、最後に正答率と間違えた語の一覧を表示します。

### 答え方
- **入力**：大文字小文字、記号、空白、先頭の the の有無は区別しません。表に並んでいる同義語や形容詞形（例：stomach と gastric）はどれも正解です。1〜2文字だけ違うときは「おしい」と表示します。ただし、ileum（回腸）の問題に ileus（腸閉塞）と答えたときのように、ほかの語の英語と一致したときは「それは『腸閉塞』の英語です」と表示し、不正解にします。
- **手書き**：指やマウスで書けます。文字の自動読み取りはしません。書いたあとにお手本が出るので、見比べて自分で採点してください。

「正解にする」と「復習に回す」を押しまちがえたときは、次の問題の下にある「↩ 前の問題に戻る（採点を取り消す）」を押します。直前の問題の採点と記録が取り消され、その問題をもう一度答えられます。続けて押すと、さらに前の問題に戻れます。

テストの結果画面では、自動判定で不正解になった答えを「正解にする」で直せます。表にない言い方で正しく答えた場合に使ってください。

### キーボード操作（パソコン）
- Enter：答え合わせ、または次へ
- Esc：わからない
- 1：正解にする　2：復習に回す

## 記録の保存について

覚えた語と復習語は、その端末のブラウザの中（localStorage という保存場所）に保存されます。次の点に注意してください。

- 別のスマホやパソコン、別のブラウザとは共有されません。
- ブラウザの履歴やサイトデータを消すと、記録も消えます。
- シークレットモード（プライベートブラウズ）では、閉じると記録が消えます。
- 先生や友達が記録を見ることはできません。

## クラスに公開する方法（GitHub Pages）

GitHub Pages は、GitHub が無料で用意しているWebページの公開場所です。ファイルを置くだけでURLができます。

1. https://github.com でアカウントを作ります（持っていれば不要です）。
2. 右上の「＋」から「New repository」を選びます。名前を `kotoba-quest` にして、「Public」を選び、「Create repository」を押します。
3. 作成直後の画面で「uploading an existing file」を押し、`index.html`、`words.js`、`tips.js` をドラッグして「Commit changes」を押します。
4. 「Settings」タブを開き、左のメニューから「Pages」を選びます。
5. 「Branch」で `main` と `/ (root)` を選んで「Save」を押します。
6. 1〜2分待つと、同じ画面に `https://（ユーザー名）.github.io/kotoba-quest/` というURLが表示されます。このURLをクラスで共有します。

単語を直したいときは、GitHub 上で `words.js` を開いて鉛筆のマークから編集し、保存します。数分で公開ページに反映されます。

ほかの公開先（Netlify Drop など）でも、3つのファイルを同じ場所に置けば同じように動きます。

## 単語を追加、修正するとき

`words.js` の1行が1語です。

```js
{ ja: '胃；胃の', en: 'stomach', alt: ['gastric'], cats: ['digestive'] },
```

- `ja`：問題に出す日本語
- `en`：正解として表示する英語
- `alt`：別解（なければ `[]`）
- `cats`：分野。`digestive`（消化器系）、`swallowing`（嚥下）、`hearing`（聴覚）。複数の分野に入れることもできます

`en` を書き換えると、その語の記録は引き継がれません（記録は `en` で管理しています）。

## 覚え方と語源について

「おぼえる」モードで答えを表示すると、その下に次の3種類のメモが出ます。実践テストでは出ません。ホーム画面の「答えのあとに語源と覚え方を出す」のチェックを外すと、表示しなくなります（最初はオンです）。

| 表示 | 中身 |
|---|---|
| 📖 教科書の解説 | 教科書の「専門用語に関する解説」に載っている内容 |
| 🔤 語源 | 言葉の成り立ち（ラテン語、ギリシャ語など） |
| 💡 覚え方 | 語呂合わせや連想。覚えるために作ったもので、事実の説明ではありません |

「覚え方の種類」で「🍑 下ネタ」を選ぶと、126語すべてで 💡 覚え方の代わりに 🍑 下ネタ覚え方を出します。大人向けのきつめの内容なので、切り替えるときに一度確認が出ます。下ネタ版は `tips.js` の最後にある `TIPS_GESU` にまとめています。

教科書の英語と日本語の対応は変えていません。メモは覚えるための補足です。直したいときは `tips.js` を開き、`en`（正解の英語）と同じ名前の行を書き換えます。
